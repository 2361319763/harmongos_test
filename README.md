#### 功能介绍

纯血鸿蒙快开框架，后端对接的是若依。

本人是最近才刚开始学习鸿蒙Next的开发，就二周左右的时间，如有一些不足的地方，希望能多多交流纠正。

鸿蒙版本：HarmonyOS 5.0.1(13)

若依版本：v3.8.9

功能列表：

    1、登录页面、注册页面（开发中）
    2、多语言管理
    3、深色模式适配
    4、消息列表、deepseek对接（开发中）
    5、工作台、应用管理
    6、通讯录页面
    7、我的页面、退出登录
    8、个人资料、密码修改、头像上传（开发中）
    9、关于我们、意见反馈、版本更新、等 （开发中）

#### 使用说明

克隆代码后，使用鸿蒙开发工具直接打开就可以了

配置文件在 `entry/src/main/ets/config/Index.ets` 下面

需要将`baseUrl`改为自己的 若依后端服务地址或者直接用若依演示版本的也行
